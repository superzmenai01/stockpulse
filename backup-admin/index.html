🛠️ 永久 rule §15.45 Sscript pattern 細節

每個備份點包含 3 個 component:

  1. Annotated tag (e.g. restore-after-zigzag-4.53.0) — 永久 marker, 唔會被 future commit 改變
  2. Backup branch (e.g. backup-after-zigzag-4.53.0) — 大少可以 git checkout 入去睇
  3. Restore script (e.g. scripts/restore_after_zigzag_4.53.0.sh) — 一鍵還原, double confirm 撳 yes + RESET

對齊永久 rule §15.39「還原備份還原點」pattern + §15.45 8月31日 07:52 Sscript pattern (大少 8月31日 11:59 trigger 對齊)。

⚠️ 確認還原到 ?

還原之後, tag + branch 仍然存在, 可以用 git checkout <tag> 切返去看。

對齊 §15.45 永久 rule Sscript pattern。Backend 會自動:

  1. 拎當前 HEAD commit 拎返將來 reset 嘅 expected commit
  2. Generate scripts/restore_<name>.sh 對齊 double confirm pattern
  3. Git add + commit + push
  4. Annotated tag restore-<name> + backup branch backup-<name> + push

撳「✅ 設定」會自動做齊上述 4 步, 大少唔使記住 git command。
