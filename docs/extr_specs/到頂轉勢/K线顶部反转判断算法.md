1. 什么是顶部反转？（人话版）
================================================================================

顶部反转 = 股价涨到头了，要掉头向下了

就像爬山：
- 正常情况：你一直在往上爬，体力（指标）也在消耗
- 见顶信号：你还在往上爬（股价创新高），但你的腿已经软了（指标没创新高）
- 这就是"顶背离"——身体和动作不一致，随时可能摔下来

为什么指标会提前"知道"？
因为指标计算的是"力度"，就像汽车的油门：
- 油门踩到底（指标最高），车速最快
- 油门慢慢松了（指标下降），但车还在惯性前进（股价还在涨）
- 最后车一定会慢下来（股价下跌）

2. 最准确的指标组合
================================================================================

单一指标 = 容易出错（假信号多）
组合指标 = 相互验证，准确率大幅提升

【黄金组合：MACD + RSI + KDJ + 成交量】

┌─────────────────────────────────────────────────────────────────┐
│ 指标          │ 作用              │ 见顶信号                    │
├─────────────────────────────────────────────────────────────────┤
│ MACD          │ 趋势加速度        │ 顶背离 + 红柱缩短            │
│ RSI           │ 买卖力量温度计    │ 顶背离 + >70超买             │
│ KDJ           │ 价格弹簧          │ 顶背离 + J>100超买掉头       │
│ 成交量        │ 资金燃料          │ 上涨缩量（没油了）           │
│ 均线偏离      │ 价格引力          │ 偏离MA20超过10%              │
│ K线形态       │ 多空博弈结果      │ 乌云盖顶/看跌吞没/黄昏之星   │
└─────────────────────────────────────────────────────────────────┘

为什么这个组合最准？
- MACD：看大趋势（像看天气预报）
- RSI：看买卖力量（像看体温计）
- KDJ：看短期波动（像看脉搏）
- 成交量：看资金（像看油箱）
- 四个维度同时确认 = 准确率最高

- 0-2分：🟢 暂无见顶信号 → 继续持有

4. 算法详解
================================================================================

【4.1 MACD计算】
公式：
  DIF = EMA(12日收盘价) - EMA(26日收盘价)
  DEA = EMA(DIF, 9日)
  MACD柱状图 = (DIF - DEA) × 2

人话：
  DIF = 短期趋势 - 长期趋势（正数=上涨，负数=下跌）
  DEA = DIF的平滑线（让信号更稳定）
  柱状图 = 两条线的差距（差距越大，趋势越强）

【4.2 RSI计算】
公式：
  RSI = 100 - (100 / (1 + RS))
  RS = 平均上涨幅度 / 平均下跌幅度

人话：
  RSI = 买方力量占总力量的百分比
  70以上 = 买方透支了，要休息
  30以下 = 卖方透支了，要反弹

【4.3 KDJ计算】
公式：
  RSV = (收盘价 - N日内最低价) / (N日内最高价 - N日内最低价) × 100
  K = 2/3 × 前日K + 1/3 × 当日RSV
  D = 2/3 × 前日D + 1/3 × 当日K
  J = 3K - 2D

人话：
  RSV = 当前价格在近期区间的位置（0=最低，100=最高）
  K = RSV的平滑线（敏感）
  D = K的平滑线（稳重）
  J = K和D的放大镜（波动最大，J>100=超买，J<0=超卖）

【4.4 顶背离检测算法】
核心逻辑：
  1. 找价格的局部高点（当前点比前后5天都高）
  2. 找指标的局部高点
  3. 比较相邻两个高点：
     - 价格：后高点 > 前高点（创新高）✓
     - 指标：后高点 < 前高点（没创新高）✗
     → 顶背离确认！

6. 注意事项
================================================================================

⚠️ 重要提醒：
1. 没有任何指标100%准确，顶背离也可能"背了又背"
2. 在强势牛市中，顶背离可能多次出现才真的见顶
3. 一定要结合基本面分析，不要只看技术指标
4. 建议用日线级别判断，分钟线噪音太多
5. 大盘股的信号比小盘股更可靠

⚠️ 常见陷阱：
- 假背离：指标稍微没创新高，但很快又创新高
- 钝化：KDJ在超买区反复钝化，不能机械判断
- 滞后：MACD是滞后指标，可能错过最佳卖点
